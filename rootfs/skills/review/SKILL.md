---
name: review
description: Review current code changes for bugs, style, and improvements
---

Review the current code changes. Follow these steps:

1. Run `git diff` to see all unstaged changes
2. Run `git diff --staged` to see staged changes
3. Analyze the changes for:
   - Correctness and potential bugs
   - Code style and consistency
   - Performance concerns
   - Security issues
4. Provide a clear summary of findings with specific line references
